# Ручная проверка интерфейса FlowVPN 1.4.3 — архив

[Разработка](DEVELOPMENT.md) · [Выпуск версии](RELEASING.md)

Этот документ сохраняет результаты конкретной ручной сессии версии 1.4.3. Текущие изменения и их проверки описаны в [отчёте 1.5.1](VALIDATION-1.5.1.md), а предыдущий полный автоматизированный прогон — в [отчёте 1.5.0](VALIDATION-1.5.0.md). Изменившиеся после этой сессии формы профиля, переключение подключения и адаптивная компоновка требуют собственных проверок; результаты ниже на них не переносятся.

**Дата: 7 ноября 2026 года.** Проверялась локальная сборка разработчика через интерфейс приложения: действия мышью и клавиатурой выполнялись средствами Sky. Это отчёт о выполненных сценариях, а не подтверждение готовности всей системы к выпуску.

## Условия

- Windows 11 x64, масштаб интерфейса 150%.
- Широкое и компактное окно: около 1748 и 1190 физических пикселей по ширине — примерно 1180 и 800 DIP.
- Отдельный запуск с `--preview --root <изолированный каталог>`, первоначально без настроек и профилей.
- Синтетическая конфигурация Shadowsocks в JSON с адресом `192.0.2.1`. Реальные подключения и пользовательские конфигурации не использовались; VPN не запускался.

## Отображение и взаимодействие

Проверены светлая и тёмная темы, компактный сайдбар, расположение каталога и редактора друг под другом в узком окне, а также две колонки карточек в диалоге. Нижние действия доступны при прокрутке перетаскиванием полосы прокрутки.

В ходе проверки исправлены следующие замечания:

| Замечание | Состояние после правки |
| --- | --- |
| «Позже» оставалась основной кнопкой после выбора | Повторно проверен переход **0 → 1 → 0**: создание недоступно без выбора, становится основным действием после выбора и снова отключается после снятия отметки. |
| Цвет выбранной карточки менялся с бирюзового на синий при наведении | Повторно проверено согласованное бирюзовое выделение при наведении. |
| Старое сообщение о создании профилей занимало место на другой странице | Повторно проверено скрытие сообщения при переходе между страницами. |
| Подсказки не учитывали количество выбранных наборов и перестановку панелей | Уточнены условие «не меньше двух» и текст без привязки к левой панели. |
| После переименования оставалось сообщение со старым названием | Повторно проверено сообщение с новым названием. |
| Переключение темы возвращало длинную подпись в компактный сайдбар | Повторно проверены три переключения **тёмная → системная → светлая → тёмная** при ширине около 800 DIP без изменения размера окна: оставался только значок, тема и доступное имя кнопки обновлялись. |

## Границы проверки

В этой сессии не проверялись установка и обновление MSIX, реальные VPN-подключения, UAC и работа туннеля, сетевые утечки, режим высокой контрастности и другие версии ОС. Не выполнялось фактическое удаление набора через интерфейс. Успешные сценарии выше не заменяют эти испытания.
