# Установка FlowVPN

[← К README](../README.md)

Основной формат поставки — **MSIX для Windows x64**. В него входят приложение, закреплённая версия sing-box, .NET и Windows App SDK. Отдельная установка движка не нужна.

Готовится версия 1.4.2; публичный бинарный выпуск и испытание установки/обновления на чистой ОС ещё не завершены. Когда выпуск появится, установочный комплект будет доступен на [странице Releases](https://github.com/vserdobintsev/FlowVPN/releases).

## Требования

- Windows x64. Минимальная версия в манифесте — Windows 10 build 19041; совместимость на всех заявленных версиях ещё проверяется.
- Доступ к совместимому серверу OpenVPN или Outline. FlowVPN не выдаёт серверы и ключи доступа.
- Устанавливать клиенты OpenVPN Connect и Outline не нужно: данные подключения добавляются непосредственно в FlowVPN.
- Возможность подтвердить UAC при добавлении сертификата и подключении VPN.
- Для установщика достаточно встроенного Windows PowerShell 5.1. PowerShell 7 нужен только для отдельного инструмента переноса прежних настроек.

## Установочный комплект

Распакуйте архив полностью. Эти файлы должны находиться рядом:

| Файл | Назначение |
| --- | --- |
| `FlowVPN-<version>-x64.msix` | Приложение и движок |
| `FlowVPN.cer` | Открытый сертификат издателя |
| `Install-FlowVPN.cmd` | Запуск установщика штатным PowerShell |
| `Install-FlowVPN.ps1` | Проверка подписи, запрос доверия и установка |
| `Test-PackagePayload.ps1` | Проверка связи подписи с содержимым пакета |

Запустите **`Install-FlowVPN.cmd` обычным двойным щелчком**, без «Запуск от имени администратора». Установщик проверит пакет и сертификат, покажет сведения об издателе и при необходимости запросит согласие на доверие. Отдельное окно UAC появится только для добавления сертификата. MSIX затем устанавливается для исходного пользователя.

Приложение появится в меню «Пуск». Установщик не открывает его и не подключает VPN автоматически. Перед первым запуском закройте прежнюю копию FlowVPN, включая её экземпляр в трее. Если нужно сохранить настройки из предпросмотра, выполните [перенос](#перенос-настроек) до первого запуска.

## Почему Windows спрашивает о сертификате

Пакет подписан собственным сертификатом **`CN=FlowVPN`**. У него нет цепочки доверия к общедоверенному центру сертификации, поэтому пользователь подтверждает доверие отдельно на каждом ПК.

Установщик добавляет только открытый сертификат в `LocalMachine\TrustedPeople`. Это влияет на пользователей данного компьютера; корневые центры сертификации не изменяются. Закрытый ключ PFX в установочный комплект не входит.

SHA-256 текущего открытого сертификата:

```text
D9BF1FF74EFF7D2AB72BD89DA624564FF6C56C551002BE3493038AF13A87C854
```

Лаунчер CMD закрепляет этот отпечаток, а скрипт проверяет совпадение сертификата с подписью MSIX. Доверие подписи и возможность установки окончательно проверяет Windows. Собственный сертификат не означает независимую проверку издателя или аудит приложения.

При обычном обновлении тем же сертификатом повторять доверие не нужно. Если ключ заменён, потребуется принять новый сертификат. Порядок замены и действий при компрометации описан в [инструкции восстановления подписи](../src/FlowVPN.WinUI/Distribution/SIGNING-RECOVERY.md).

## Первое подключение

1. В настройках → «Подключения» нажмите «Добавить подключение». Вставьте данные или выберите файл: FlowVPN покажет распознанный формат перед сохранением. Выбирать тип заранее не нужно. При первом запуске без подключений приложение открывает этот раздел.
2. Выберите профиль и укажите источник. Добавьте приложения или домены, которые должны использовать выбранный маршрут.
3. В общих настройках включите или выключите базу RunetFreedom и выберите доменную категорию. Эта настройка действует для всех профилей.
4. Если другой VPN уже работает, отключите его. Нажмите «Подключить» в FlowVPN и подтвердите UAC для той же учётной записи Windows; интерфейс останется обычным процессом.

Способ добавления зависит только от имеющихся данных:

| Что у вас есть | Как добавить |
| --- | --- |
| Файл конфигурации OpenVPN | Выберите файл; можно выбрать несколько. Внешние локальные сертификаты и ключи читаются относительно папки конфигурации. |
| Текст конфигурации OpenVPN | Вставьте текст с включёнными блоками `ca`, `cert` и `key`. Для конфигурации со ссылками на отдельные файлы используйте выбор файла. |
| Ключ `ss://` или `ssconf://` | Вставьте ключ. Динамический ключ загружается только после подтверждения добавления, затем обновляется перед подключением. |
| JSON Shadowsocks | Вставьте или откройте поддерживаемый объект с адресом, портом, методом и паролем. Неизвестные параметры не отбрасываются молча. |
| Адрес, порт, метод и пароль Shadowsocks | Откройте вторичную форму параметров сервера. Одного адреса недостаточно, чтобы определить протокол автоматически. |
| Подключения в установленном клиенте | Используйте отдельную команду переноса из клиентов. Она не является обязательным этапом. |

Расширение файла само по себе не определяет протокол: проверяется содержимое. Автоопределение не выполняет подключение или сетевой запрос и не означает поддержку всех параметров найденного формата. Неподдерживаемые возможности OpenVPN или Shadowsocks будут явно отклонены.

Одновременная работа нескольких VPN-клиентов может менять маршруты и DNS; этот сценарий не является проверенным режимом FlowVPN. Изменения правил вступают в силу при следующем подключении.

Закрытие окна сворачивает приложение в трей. Для отключения используйте команду приложения или меню трея. Автозапуск интерфейса включается отдельно и не включает автоматическое подключение VPN.

## Перенос настроек

Этот раздел нужен для перехода с прежней копии FlowVPN. Для новой установки импорт не требуется.

После установки MSIX, **до первого запуска**, закройте все экземпляры FlowVPN и откройте PowerShell **7.4 или новее** под той же учётной записью Windows на том же компьютере. Настройки защищены DPAPI; перенос зашифрованного файла на другой ПК или другую учётную запись сам по себе не переносит возможность расшифровки.

Из корня исходников сначала выполните проверку:

```powershell
./src/FlowVPN.WinUI/Distribution/Import-FlowVPNSettings.ps1 `
  -SourceData 'C:\Path\To\PreviousFlowVPN\data' `
  -ValidateOnly
```

Затем выполните ту же команду без `-ValidateOnly`. Если скрипт находится рядом с установочным комплектом, замените путь к нему на `./Import-FlowVPNSettings.ps1`.

Дополнительные параметры:

| Параметр | Назначение |
| --- | --- |
| `-RulesSource <папка>` | Кэш общей базы, если он хранится отдельно от прежней `data` |
| `-ValidateOnly` | Проверка без записи; установленный MSIX не требуется |
| `-WhatIf` | Показ предполагаемого действия без переноса |
| `-PackageName FlowVPN.Preview` | Явный выбор отдельного тестового пакета; по умолчанию используется `FlowVPN` |

Скрипт сверяет имя и издателя установленного пакета, структуру настроек и хеши известных файлов кэша. При включённой базе нужны корректные GeoIP и выбранная доменная категория. Существующие настройки и заполненный кэш назначения не перезаписываются. Журналы и временные рабочие конфигурации не копируются.

## Обновления

Версии FlowVPN и sing-box поставляются вместе: замена движка проходит проверку совместимости и входит в новый выпуск приложения. Правила RunetFreedom обновляются отдельно.

Каналы `stable` и `preview` имеют разные идентичности MSIX и отдельные настройки. Переключение между ними является отдельной установкой. До публикации подписанного выпуска публичный канал обновлений недоступен; адреса каналов добавляет release workflow при сборке для конкретного репозитория.

## Если возникла ошибка

Сохраните текст ошибки и версию Windows. Для обращения используйте [правила поддержки](../SUPPORT.md). Не публикуйте ключи доступа, `settings.dat`, `runtime.json`, полную папку данных или необработанные журналы: они могут содержать сведения о подключениях.

Функция kill switch не заявлена. Перед использованием проверьте маршрутизацию для нужных приложений в своей сети; подробные границы защиты — в [SECURITY.md](../SECURITY.md).
