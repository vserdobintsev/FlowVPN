# Проверка предварительного выпуска 1.5.3

Пакет собран из `a34f21d3e194528e89f45dda9a79daa64b73d057`. Дерево исходников совпадает с результатом объединения PR #7; последующая подготовка описания выпуска меняет только документацию.

## Выполнено

- 803 изолированные автоматические проверки: 548 функциональных, 108 проверок брокера, 11 локального API, 33 трафика, 29 аватарки, 38 выпуска и 36 обновлений.
- Проверены обрыв загрузки и продолжение по Range, ответ сервера без поддержки Range, ровно три попытки при повторных сбоях, сохранение части между вызовами, неверные диапазоны, SHA-256, отмена, срок хранения и число файлов кэша. Жёсткие ссылки отклоняются до сетевого запроса и изменения содержимого.
- Сборки Release и Preview, Outline transport, CodeQL C#/Python и проверка сообщений коммитов завершились успешно на GitHub для исходного коммита пакета.
- Подписанный MSIX: проверены 616 файлов и 6184 блока, Windows признала подпись действительной; временная метка RFC 3161 присутствует. Проверки изменённого содержимого, пересчитанных хешей со старой подписью и постороннего файла прошли в PowerShell 7 и Windows PowerShell 5.1.
- Пользователь подтвердил успешную работу подключения на своём ПК. Это подтверждение не заменяет отдельную матрицу приёмки.
- Предыдущие автоматические проверки интерфейса и их ограничения описаны в [отчёте 1.5.1](VALIDATION-1.5.1.md).

## Что ещё проверять

Чистая установка Windows, разные DPI и поддерживаемые сборки ОС, сон и смена адаптеров, длительная работа, полная матрица IPv4/IPv6/DNS/QUIC и настоящий обрыв большой загрузки из установленной версии. Испытания докачки выше используют управляемые тестовые HTTP-ответы. Независимый аудит безопасности не проводился. Общесистемный kill switch не реализован.

Выпуск помечен **Pre-release** и не является стабильным обновлением. Это не режим Preview приложения: пакет содержит рабочий VPN. Для первой установки нужен собственный сертификат из полного установочного комплекта; Windows запросит согласие на добавление доверия.
