| Ситуация | Куда обратиться |

| Остальные вопросы | [vladislav.serdobintsev@gmail.com](mailto:vladislav.serdobintsev@gmail.com) |

Перед созданием issue проверьте существующие сообщения и [известные ограничения](SECURITY.md#что-остаётся-до-публичного-стабильного-релиза). Для ошибки полезны точная версия FlowVPN, версия и сборка Windows из `winver`, последовательность действий, ожидаемый результат и фактическое поведение. Отдельно укажите, установлено ли приложение через MSIX или запущено из сборки разработчика.

Если ошибка связана с дополнительным модулем, укажите его название, версию и сообщение из панели операции. Выпуск модуля и выпуск самого FlowVPN имеют отдельные версии; наличие модуля в GitHub Releases не означает публикацию новой версии приложения.

FlowVPN не предоставляет VPN-серверы и ключи доступа. Если сервер недоступен или ключ перестал действовать, его должен проверить ваш провайдер или администратор. Для диагностики ошибки FlowVPN достаточно описания симптомов и обезличенного примера; отправлять рабочий ключ не нужно.

## Что нельзя прикладывать публично

Не загружайте полные папки приложения, `data`, `settings.dat`, `runtime.json`, PFX, ключи Outline, настоящие OpenVPN-конфигурации или необработанные журналы. В них могут находиться пароли, сертификаты с закрытым ключом, адреса серверов и секрет управляющего API.

Для скриншота или короткого фрагмента журнала сначала удалите чувствительные данные, включая имя пользователя и личные пути. Если для воспроизведения требуется конфигурация, замените её синтетическим примером. Не отключайте проверку TLS и защиту Windows ради подготовки отчёта.
